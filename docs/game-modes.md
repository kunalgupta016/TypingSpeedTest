# Game modes

Each catalog game now has a distinct rule set in addition to its shared keyboard, timer, and result screen.

| Game | Its rule |
| --- | --- |
| Zen Test | Open typing passage with no interruptions for mistakes. |
| Key Forge | A wrong key holds the cursor until the target letter is correct. |
| Word Rain | Type any falling word and press Enter to clear it before it reaches the floor. Misses cost lives; clean clears build score and combo. |
| Star Blaster | Multiple ship targets fall. The first letter locks a target; finish its word to destroy it. Misses cost lives and clean hits build combo. |
| Race Day | Race your prompt progress against a 45 WPM pace car. |
| Night Watch | The round ends when you lose three lives to mistakes. |
| Slice | Short number tokens award points when completed. |
| Lane Runner | Completing words moves the runner through three lanes. |
| Maze Keys | Follow a seeded route with arrow keys or the on-screen direction pad. |
| Express Rush | Score double points during the first half of the round. |
| Defuse | Each mistake removes three seconds from the clock. |

All modes still use the shared metrics and local run storage. Maze routes and target words are seeded, so the same seed produces the same opening content.
